Ton jumeau ou ta jumelle numérique : par où commencer

Trois gestes, dans l'ordre. Compte une heure, surtout passée à regarder Claude travailler. Tu n'as aucune commande à taper.

Il te faut : un abonnement Claude payant à ton nom (Pro, ou Max si tu t'en sers beaucoup), et ton ordinateur, Windows ou Mac.

1. Accepter l'invitation de GitHub

Cinq minutes. GitHub, c'est là que ton jumeau ou ta jumelle est sauvegardé.

  1. Ouvre le courriel de GitHub qui t'invite à rejoindre EB-jumeaux. Regarde aussi tes indésirables.
  2. Clique sur le bouton du courriel. Si tu n'as pas de compte GitHub, crée-le avec cette même adresse de courriel. C'est gratuit.
  3. Accepte l'invitation.

Ensuite : GitHub t'amène sur une page au nom de EB-jumeaux. Il n'y a rien à faire sur cette page. Ferme-la et reviens ici, au geste 2.

2. Préparer l'application Claude

Dix minutes, une seule fois.

  1. Installe l'application Claude sur ton ordinateur (claude.ai/download) et connecte-toi à ton compte.
  2. Dans l'application : Paramètres, puis Claude Code. Active « Autoriser le mode de contournement des autorisations » et « Connecter les nouvelles sessions à Remote Control ».
  3. Crée un dossier jumeau (en minuscules) dans tes Documents.
  4. Dans l'application, onglet Code : « Choisir un environnement », puis crée un nouvel environnement. Onglet Local, nom Jumeau, « Exécuter dans » : Cet ordinateur, puis sous Dossiers, « + Ajouter » et choisis ton dossier jumeau. Clique « Créer l'environnement ».
  5. Ouvre une nouvelle session sur Jumeau. Sous la zone de saisie, choisis « Ignorer les permissions ».

Sur PC : si tes Documents sont dans OneDrive, crée plutôt le dossier jumeau directement dans ton dossier personnel (C:\Users\ton nom). Si tu l'oublies, Claude s'en apercevra et te le proposera.

3. Coller ce texte dans Claude

Dans la session que tu viens d'ouvrir. Claude fait tout le reste.

Bonjour Claude. Je ne suis pas technique, fais le travail pour moi et
parle-moi simplement, et ne fais rien de destructif. Prépare mon poste et
installe le cerveau de mon jumeau numérique. Ne me fais rien taper, et
dis-moi avant chaque fenêtre du système que je vais devoir accepter.
1. Git. Vérifie s'il est installé. Sinon, installe-le par
   winget install --id Git.Git -e --source winget
2. Python. Installe uv par l'installateur officiel d'Astral, dans mon compte,
   sans droits d'administrateur, puis Python 3.12 par
   uv python install 3.12 --default.
3. L'outil GitHub. Installe gh par
   winget install --id GitHub.cli -e --source winget
   Utilise les chemins complets, mon application ne voit pas encore le
   nouveau PATH. Vérifie que git, python et gh répondent avec leur version.
4. Demande-moi mon prénom, mon nom et mon courriel, puis configure git à
   cette identité.
5. Connecte gh à GitHub par mon navigateur avec
   gh auth login --hostname github.com --git-protocol https --web
   puis gh auth setup-git. Montre-moi le code à usage unique qu'il affiche,
   je le saisirai moi-même dans la page de GitHub. Ne me demande jamais un
   mot de passe ni un jeton dans cette conversation. Si la commande attend
   une touche que tu ne peux pas donner, arrête-toi et dis-le-moi.
6. Le dossier de travail est celui de cette session, Documents\jumeau.
   Avant de cloner, si le chemin de ce dossier contient OneDrive, arrête-toi :
   propose-moi de créer plutôt le dossier jumeau directement dans mon dossier
   personnel, hors de OneDrive, et attends mon accord. Clone dedans
   https://github.com/EB-jumeaux/gabarit-jumeau.git, le contenu
   directement dans ce dossier, pas dans un sous-dossier. Crée ensuite le fichier .env à partir de .env.exemple et mets-y la ligne
   GABARIT_DEPOT=https://github.com/EB-jumeaux/gabarit-jumeau.git
   (ce n'est pas un secret, c'est l'adresse d'où viennent mes mises à jour).
7. Crée MON dépôt privé à moi avec gh repo create jumeau --private, puis fais pointer le dossier dessus avec git remote set-url
   origin, et pousse tout. Vérifie que la branche s'appelle bien main avant
   de pousser, et qu'après la poussée git remote -v montre MON dépôt, et
   plus le modèle.
8. Vérifie que le dossier contient CLAUDE.md, profile/ et tools/, et que
   python tools/maj_jumeau.py --verifier répond sans erreur.
9. Fais-moi un compte rendu en langage simple, une ligne par point. Si un
   point échoue, montre-moi le message d'erreur exact pour que je le
   transmette. Termine en me disant de quitter complètement l'application
   Claude et de la rouvrir avant ma première vraie session.

  1. Colle le texte dans la session, puis appuie sur Entrée. Il n'y a rien à modifier.
  2. Claude te demande ton nom et ton courriel. Plus tard, il te montre un code de huit caractères et ouvre une page de GitHub : saisis-y le code et autorise. Si une fenêtre de ton ordinateur demande une confirmation, accepte-la.
  3. Quand Claude a fini, quitte complètement l'application Claude, puis rouvre-la.

Ensuite : onglet Code, nouvelle session sur Jumeau, et écris Bonjour. Ton jumeau ou ta jumelle se présente et te pose des questions pour apprendre qui tu es et comment tu écris. Dis-lui aussi ce qu'il doit couvrir : ton travail, ta vie personnelle, ou les deux.
