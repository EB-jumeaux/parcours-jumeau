Your digital twin: where to start

Three steps, in order. Allow an hour, mostly spent watching Claude work. You have no commands to type.

You need: a paid Claude subscription in your name (Pro, or Max if you use it a lot), and your computer, Windows or Mac.

1. Accept the GitHub invitation

Five minutes. GitHub is where your twin is backed up.

  1. Open the email from GitHub that invites you to join EB-jumeaux. Check your spam folder too.
  2. Click the button in the email. If you don't have a GitHub account, create it with that same email address. It's free.
  3. Accept the invitation.

Next: GitHub takes you to a page named EB-jumeaux. There is nothing to do on that page. Close it and come back here, to step 2.

2. Set up the Claude app

Ten minutes, only once.

  1. Install the Claude app on your computer (claude.ai/download) and sign in to your account.
  2. In the app: Settings, then Claude Code. Turn on the setting that allows bypassing permissions, and the one that connects new sessions to Remote Control.
  3. Create a folder named jumeau (lowercase) in your Documents.
  4. In the app, Code tab: choose an environment, then create a new one. Local tab, name Jumeau, run on This computer, then under Folders, add your jumeau folder. Create the environment.
  5. Open a new session on Jumeau. Below the input box, choose the option to bypass permissions.

On a PC: if your Documents are in OneDrive, create the jumeau folder directly in your user folder instead (C:\Users\your name). If you forget, Claude will notice and offer to fix it.

3. Paste this text into Claude

In the session you just opened. Claude does everything else.

Hello Claude. I'm not technical, so do the work for me and
speak to me simply, and don't do anything destructive. Prepare my computer and
install the brain of my digital twin. Don't make me type anything, and
tell me before each system window I'll have to accept.
1. Git. Check whether it's installed. If not, install it with
   winget install --id Git.Git -e --source winget
2. Python. Install uv with Astral's official installer, in my account,
   without administrator rights, then Python 3.12 with
   uv python install 3.12 --default.
3. The GitHub tool. Install gh with
   winget install --id GitHub.cli -e --source winget
   Use full paths, my app can't see the new PATH yet.
   Check that git, python and gh respond with their version.
4. Ask me for my first name, last name and email, then configure git
   with that identity.
5. Connect gh to GitHub through my browser with
   gh auth login --hostname github.com --git-protocol https --web
   then gh auth setup-git. Show me the one-time code it displays,
   and I'll enter it myself on the GitHub page. Never ask me for a
   password or a token in this conversation. If the command waits for
   a key you can't press, stop and tell me.
6. The working folder is this session's folder, Documents\jumeau.
   Before cloning, if this folder's path contains OneDrive, stop:
   suggest creating the jumeau folder directly in my personal
   folder instead, outside OneDrive, and wait for my approval. Clone into it
   https://github.com/EB-jumeaux/gabarit-jumeau.git, with the contents
   directly in this folder, not in a subfolder. Then create the .env file from .env.exemple and add the line
   GABARIT_DEPOT=https://github.com/EB-jumeaux/gabarit-jumeau.git
   (it isn't a secret, it's the address my updates come from).
7. Create MY own private repository with gh repo create jumeau --private, then point the folder to it with git remote set-url
   origin, and push everything. Check that the branch is named main before
   pushing, and that after the push git remote -v shows MY repository, and
   no longer the template.
8. Check that the folder contains CLAUDE.md, profile/ and tools/, and that
   python tools/maj_jumeau.py --verifier runs without errors.
9. Give me a report in plain language, one line per item. If an
   item fails, show me the exact error message so I can
   pass it on. End by telling me to fully quit the Claude
   app and reopen it before my first real session.

  1. Paste the text into the session, then press Enter. There is nothing to change.
  2. Claude asks for your name and email. Later, it shows you an eight-character code and opens a GitHub page: enter the code there and authorize. If a window on your computer asks for confirmation, accept it.
  3. When Claude is done, quit the Claude app completely, then reopen it.

Next: Code tab, new session on Jumeau, and type Hello. Your twin introduces itself and asks you questions to learn who you are and how you write. Also tell it what it should cover: your work, your personal life, or both.
